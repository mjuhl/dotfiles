# Neovim setup notes

## Keymappings

### Normal Mode

- `;` - maps to `:`
- `<Esc>` - clears search highlights
- `<leader>/` - toggles comment on current line
- `<leader>bd` - closes current buffer while preserving window layout
- `<tab>` - selects next file in bufferline
- `<s-tab>` - selects previous file in bufferline
- `<leader>h`
    - `a` - appends current file position to harpoon list
    - `A` - prepends current file position to harpoon list
    - `C` - clears the harpoon list
    - `l` - displays the harpoon list interface
    - `1` - selects first item in harpoon list
    - `2` - selects second item in harpoon list
    - `3` - selects third item in harpoon list
    - `4` - selects fourth item in harpoon list
- `<leader>s`
    - `f` - searches files
    - `g` - searches by grep
    - `w` - searches for current word under the cursor
    - `r` - searches for recently opened files
    - `o` - searches open files
    - `h` - searches help
    - `d` - searches diagnostics
    - `k` - searches keymaps
    - `l` - resumes last search
    - `m` - searches editor messages
- `<leader>e` - shows file tree sidebar
- `<leader>gd` - goto definition
- `<leader>gr` - goto references
- `<leader>ca` - code actions
- `<leader>bf` - run formatter on current buffer
- `<C-/>` - toggle terminal
